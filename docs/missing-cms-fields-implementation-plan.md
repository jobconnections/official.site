# バックエンド設定項目のフロントエンド反映状況調査および実装計画書

## 1. 概要・背景

Sveltia CMS（`public/admin/config.yml`）および Astro コンテンツコレクション（`src/content.config.ts`）において設定可能な求人情報の各フィールドと、閲覧者向けフロントエンド画面（求人一覧、求人詳細、応募フォーム）の実装状況を照合しました。

その結果、**「バックエンド側で入力・設定可能であるにもかかわらず、フロントエンド画面に表示されていない、または連動していない項目」**が複数確認されました。
本ドキュメントでは、これらの未反映項目を重要度別にリスト化し、フロントエンドへの実装計画を策定します。

## 3. 未反映項目の詳細分析

### 【重要度：高】求職者の利便性・業務運用に直結する項目

#### 1. 応募受付の電話番号 (`applicationPhone`)
* **バックエンド側設定:** 応募受付先の電話番号を入力可能。
* **フロントエンド現状:** 求人詳細ページ（全言語）の問い合わせエリアには「フォーム応募」「WhatsApp」「LINE」「メール」しか配置されておらず、**「電話で応募・問い合わせる（`tel:...`）」ボタンや電話番号のテキスト表示が一切存在しない**。
* **改善案:** `applicationPhone` が設定されている場合、詳細ページの応募導線に「電話で応募する（059-xxx-xxxx）」ボタンを追加。

#### 2. 日本語能力要件 (`japaneseSpeaking`, `japaneseReading`, `japaneseWriting`, `japaneseJlpt`)
* **バックエンド側設定:** 会話・読み・書き・JLPTの4指標を設定可能。
* **フロントエンド現状:**
  * 英語 (`en`) およびポルトガル語 (`pt-br`) の求人詳細ページには表示セクションがあるが、**日本語版詳細ページ（`/jobs/[slug].astro`）にはセクション自体が完全に欠落**している。
  * 求人一覧カード（`JobCard.astro`）でも `lang !== 'ja'` の条件分岐があるため、日本語版では表示されない。
  * 日本語版求人一覧（`jobs/index.astro`）では `data-japanese-speaking` 属性が付与されておらず、フィルタ連動が壊れている。
  * `JobFilter.astro` では、セレクトボックスのラベルが会話レベルとJLPTレベルで混在している。
* **改善案:**
  * 日本語版求人詳細ページにも「必要とされる日本語能力」セクションを追加。
  * 日本語版求人一覧のカード要素に data 属性を付与。
  * 求人カードおよびフィルタで会話/JLPTを適切に表示・絞り込めるように改修。

#### 3. 応募フォームと求人設定の連動 (`requiredInfo`, `requirePhone`)
* **バックエンド側設定:**
  * `requiredInfo`: 「氏名・連絡先のみ」「基本情報」「基本情報 + 職務経歴」から選択。
  * `requirePhone`: 電話番号を必須にするかどうかの真偽値。
* **フロントエンド現状:**
  * 求人詳細から `/apply/` へ遷移する際にクエリパラメータ（求人IDやタイトル）が渡されていない。
  * 応募フォーム（`/apply/`, `/en/apply/`, `/pt-br/apply/`）は静的固定となっており、CMSで「氏名・連絡先のみ」を選択しても**常に「履歴書・職務経歴書」が必須（required）**になっている。
  * `requirePhone: true` に設定されていても、フォーム側の電話番号は**常に「任意」**のまま。
* **改善案:**
  * 詳細ページの応募ボタンを `/apply/?job=JOB2026xxxx&title=...` のようにパラメータ付きリンクに変更。
  * 応募フォーム上部に応募対象の求人名を表示。
  * `requiredInfo` や `requirePhone` の設定に応じ、JavaScriptで入力欄の必須属性（required / 必須バッジ）を動的に切り替える（または求人詳細ページ上に応募必要書類を明記）。

---

### 【重要度：中】情報提供の正確性・一覧性向上

#### 4. 給与上限金額 (`salaryUpperLimit`)
* **バックエンド側設定:** 給与上限額を数値で設定可能（例: 下限1,350円、上限1,650円）。
* **フロントエンド現状:**
  * 求人詳細ページには `1,350円〜1,650円` と表示されるが、**求人一覧カード（`JobCard.astro`）では常に下限額のみが表示される（「時給 1,350円」）**。
  * `JobFilter.astro` には下限額フィルタ（〜円以上）しかなく、仕様書に記載のある「給与上限」での絞り込みができない。
* **改善案:**
  * `JobCard.astro` の給与テキスト生成ロジックに `salaryUpperLimit` を反映（「時給 1,350円〜1,650円」）。
  * 一覧の data 属性に `data-salary-upper` を追加し、上限額でのフィルタも可能にする。

#### 5. 掲載終了日・有効期限 (`validThrough`)
* **バックエンド側設定:** 掲載終了日（`YYYY-MM-DD`）を設定可能。
* **フロントエンド現状:**
  * Google お仕事検索用の JSON-LD 構造化データには出力されているが、**求職者が見る画面UI上にはどこにも表示されていない**。
* **改善案:**
  * 求人詳細ページの掲載日（`datePosted`）の横に「応募締切 / 掲載終了日: YYYY年MM月DD日」を表示。
  * 求人一覧カードにも掲載終了日を表示（任意設定されている場合）。

#### 6. 職種区分 (`jobCategory`)
* **バックエンド側設定:** 「工場・製造」「ITエンジニア」等の21区分から選択。
* **フロントエンド現状:**
  * 求人詳細には表示されるが、**求人一覧カードにはタグ・バッジとしての表示がない**。
  * **求人一覧フィルタ（`JobFilter.astro`）に職種別の絞り込みが存在しない**。
* **改善案:**
  * 求人一覧カードに職種区分のバッジを追加。
  * `JobFilter.astro` に職種区分のセレクトボックスを追加し、絞り込みできるように拡張。

## 4. 実装計画（フェーズ分け）

### フェーズ 1: 求人詳細ページの反映（重要度：高） 【✅ 実装完了】
1. **日本語版求人詳細 (`src/pages/jobs/[slug].astro`) の改修** 【完了】
   * 日本語能力セクション（会話・読み・書き・JLPT）を追加（`japaneseSpeaking`, `japaneseReading`, `japaneseWriting`, `japaneseJlpt`）。
   * 掲載終了日（`validThrough`）をヘッダー情報エリアに「応募締切」バッジとして追加表示。
   * 応募必要項目（`requiredInfo`）の案内表示（「選考・応募について」内）を追加。
   * 応募受付電話番号（`applicationPhone`）が存在する場合、「電話で応募する」ボタン（`tel:` リンク）を追加。
2. **多言語版詳細ページ (`en`, `pt-br`) の追従改修** 【完了】
   * 掲載終了日（`validThrough`）の表示（Deadline / Prazo）。
   * 応募必要項目（`requiredInfo`）の案内表示（多言語対応ラベル変換）。
   * 電話応募ボタン（`applicationPhone`）の追加（Call to Apply / Ligar para Candidatar）。

### フェーズ 2: 求人一覧カードおよび検索フィルタの改修（重要度：中） 【未着手】
1. **`src/components/JobCard.astro` の改修**
   * 給与上限（`salaryUpperLimit`）を考慮した金額テキストの表示。
   * 職種区分（`jobCategory`）のバッジ表示。
   * 掲載終了日（`validThrough`）の表示（設定時のみ）。
   * 日本語版カードでも必要に応じて日本語レベルを表示。
2. **`src/components/JobFilter.astro` および一覧ページ（`ja`, `en`, `pt-br`）の改修**
   * 日本語版一覧に `data-japanese-speaking`, `data-job-category`, `data-salary-upper` 等の data 属性を追加。
   * フィルタに「職種区分（`jobCategory`）」セレクトボックスを追加。
   * フィルタに「給与上限額」の入力欄を追加。
   * 日本語レベル選択肢（会話 vs JLPT）の整理とバグ修正。

### フェーズ 3: 応募フォームとの連動（重要度：高） 【未着手】
1. **応募導線における求人情報引き継ぎ**
   * 求人詳細の「フォームから応募する」リンクに `?job=JOBID&title=...` を付加。
2. **応募フォーム (`apply/index.astro`, `en`, `pt-br`) の動的対応**
   * URLパラメータから求人情報を取得し、「応募先求人: ○○○○」を表示。
   * 隠しフィールド `<input type="hidden" name="applied-job" />` に求人情報を格納。
   * `requiredInfo` / `requirePhone` に応じた入力項目の必須属性切り替え。
